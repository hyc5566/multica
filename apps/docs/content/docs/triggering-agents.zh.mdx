---
title: 讓 Agent 開始工作
description: 觸發 Agent 的四種方式，以及觸發之後去哪裡查看進展。
---

在 Multica 中，Agent 不會自己開始工作。每一次執行都由一個明確的動作觸發。共有四種方式：

| 方式 | 適用場景 | 操作 |
| --- | --- | --- |
| **分配任務** | 這項工作由 Agent 全程負責 | [分配任務給 Agent](/assigning-issues)，任務處於 `todo` 或更靠後的狀態時立即開始 |
| **在留言中 @Agent** | 請 Agent 處理一條具體請求，不改變任務的負責人 | [在留言中 @它](/mentioning-agents)，也可以直接回覆 Agent 的留言繼續對話 |
| **直接對話** | 一個問題或一次嘗試，不需要建任務 | [和 Agent 開始對話](/chat)，每條消息觸發一輪執行 |
| **自動化** | 重複性工作，希望按時間或外部事件自動進行 | [建立自動化](/autopilots)，由時間表、webhook 或手動觸發 |

四種方式共用以下規則：

- 你只能觸發自己**有權限執行**的 Agent，由 Agent 的 Access 設定決定，與你的工作區角色無關。
- 在任務中觸發前，輸入框下方會顯示**觸發預覽**，明確列出這條內容會喚醒誰；不想觸發任何 Agent 時，用 `/note` 留言。
- 處於 `backlog` 的任務不會觸發執行；把它移到 `todo` 後，已分配的 Agent 才會開始。

## 查看進展

每次觸發都會建立一次[執行](/tasks)。進展會實時寫回觸發它的地方——任務的時間線或對話窗口；在執行日誌裡可以查看完整過程、停止執行或重試。

執行遲遲未開始時，多數是執行環境不在線，按[故障排查](/troubleshooting)中"執行不開始"一節檢查。
