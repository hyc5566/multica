先看你希望Agent做什麼：負責一條任務、處理一次具體請求，還是按固定安排反覆工作。

<TriggerChooserDemo />

| 你想做什麼 | 使用什麼 |
|---|---|
| 讓Agent負責一條任務 | 把[任務分配](/assigning-issues)給Agent或小隊。 |
| 請求幫助，保留原來的負責人 | 在留言中 [@Agent](/mentioning-agents)，或回覆它的留言繼續討論。 |
| 經常傳送同一類請求 | 儲存成[快捷操作](/quick-actions)，例如程式碼審查，在任務中直接使用。 |
| 讓任務按固定步驟交給不同處理人 | 為專案選擇[工作流](/workflows)，安排每一步由誰接手。 |
| 問一個問題，不需要新建任務 | 與Agent[開始對話](/chat)。 |
| 按時間或外部事件開展重複性工作 | 建立[自動化](/autopilots)。 |
| 讓Agent之後再回到某條任務 | 在任務上新增[喚醒](/issue-wakeups)，設好要等的時間或事件。 |

你只能呼叫自己有許可權執行的Agent。傳送留言前，檢查輸入框下方的觸發預覽；只想留言而不叫醒Agent時，使用 `/note`。處於 `backlog` 的任務會等待你準備好再開始。

## 查看進展

在發起工作的任務或對話中跟進回覆。開啟[執行日誌](/tasks)，可以檢視Agent的進展、停止或重試。工作還未開始時，先檢查Agent的電腦是否線上，後續檢查方法見[故障排查](/troubleshooting)。
