---
title: 讓 Agent 開始工作
description: 觸發 Agent 的四種方式，以及之後查看進度的位置。
---

在 Multica 中，Agent 不會自行開始工作。每次執行都由明確動作觸發，共有四種方式：

| 方式 | 適用場景 | 操作 |
| --- | --- | --- |
| **指派任務** | 由 Agent 全程負責的工作 | [將任務指派給 Agent](/assigning-issues)，任務處於 `todo` 或後續狀態時會立即開始 |
| **在留言中 @提及** | 請 Agent 處理具體要求，但不變更任務負責人 | [在留言中 @提及 Agent](/mentioning-agents)，也可以回覆 Agent 的留言接續討論 |
| **直接聊天** | 不需要建立任務的問題或快速嘗試 | [開始和 Agent 聊天](/chat)，每則訊息都會觸發一次執行 |
| **自動化** | 依排程或外部事件執行的重複工作 | [建立自動化](/autopilots)，可由排程、webhook 或手動觸發 |

四種方式共用以下規則：

- 你只能觸發自己**有權執行**的 Agent，權限由 Agent 的 Access 設定決定，與你的工作區角色無關。
- 從任務觸發 Agent 前，輸入框下方的**觸發預覽**會列出這段內容會喚起哪些 Agent；若要留言但不觸發 Agent，請使用 `/note`。
- `backlog` 狀態的任務不會觸發執行；將任務移至 `todo` 後，已指派的 Agent 才會開始工作。

## 查看進展

每次觸發都會建立一次[執行](/tasks)。進度會即時顯示在觸發來源，也就是任務時間軸或聊天視窗；執行日誌會記錄完整過程，你也可以在那裡停止或重試。

執行遲遲沒有開始時，通常是執行環境離線；請參閱[疑難排解](/troubleshooting)中的"執行沒有開始"一節。
