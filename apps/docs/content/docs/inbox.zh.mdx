收件匣彙總與你有關的工作動態，提醒你哪裡出現了需要關注的變化。它不是完整的活動日誌，前因後果仍在對應的任務裡。

## 收件匣會顯示哪些通知

常見通知包括：

- 任務分配給你，或從你名下移走；
- 你訂閱的任務出現新留言，或負責人、狀態、優先順序和日期發生變化；
- 有人在任務描述或留言中 @你；
- 你建立的任務或留言收到表情回應；
- 你訂閱的任務中，Agent執行失敗；
- [透過Agent建立任務](/issues#透過Agent建立)的操作完成或失敗；
- 你訂閱的自動化建立了新任務，或自動化因連續失敗被暫停。

你自己的操作不會通知你。同一任務的多則通知會合併為一筆；開啟後可查看任務最近的變更。

## 自動訂閱的來源

以下使用者會自動訂閱任務：

- 任務建立者；
- 新任負責人；
- 發表留言的人；
- 在任務說明中被新增 @提及的人；
- 自動化中預先設定的訂閱者。

變更負責人不會取消既有訂閱。你可以隨時在任務頁面訂閱或取消訂閱；取消後，一般更新不會再出現在收件匣，但直接 @提及你仍會個別通知。

<Callout type="info">
子任務狀態變更時，也會通知父任務的訂閱者。子任務的留言、優先順序和日期變更則不會向上通知父任務。
</Callout>

## Agent 不使用收件匣

收件匣只供工作區成員使用。即使 Agent 是任務負責人或訂閱者，也不會讀取收件匣通知。

在留言中 @Agent、把任務分配給Agent或觸發自動化，都會直接建立一次執行，不會給Agent留通知。`@all` 也只通知成員。

## 處理通知

選擇一條通知會把它標為已讀。處理完後可以歸檔，歸檔不會修改或刪除對應的任務。

<InboxDemo />

任務進入交回給人的狀態後，它的"執行失敗"通知會自動歸檔。這類狀態包括 `in_review`、`started` 分類下的自定義狀態，以及 `done`、`closed` 分類下的任一狀態。`blocked` 例外：它同樣交回給人，但工作還卡著，之前的失敗記錄還要看。

右鍵點選一條通知，可以使用**標為已讀** / **標為未讀**和**歸檔**（在"已歸檔"檢視中是**取消歸檔**）。標為未讀表達的是"我看過了，但還沒處理完"：該通知重新變為未讀，未讀數也會回升；即使它還開著也保持未讀，之後再開啟一次才會照常標為已讀。已歸檔的通知會保留已讀狀態，因此恢復時會原樣回來。

從收件匣選單還可以：

- 將全部通知標示為已讀；
- 封存全部通知，或只封存已讀通知；
- 封存 `done` 或 `cancelled` 任務的通知；
- 開啟"已封存"並還原通知。

從收件匣底部開啟**已封存**，向下捲動可載入較早的通知。篩選條件會套用至所有封存紀錄，包括尚未載入的紀錄。

## 調整通知類型

前往**設定 → 通知**，可以分別開啟或關閉以下通知：

- 指派；
- 狀態變更；
- 留言；
- 提及；
- 優先順序與日期；
- Agent 活動。

關閉某一類通知後，相關變更仍會記錄在任務中，只是不會再送到收件匣。表情反應、快速建立結果和自動化暫停等少數通知不受這六組設定控制，仍會照常送達。系統通知和瀏覽器通知只會控制桌面橫幅，不會影響收件匣本身。
