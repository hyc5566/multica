skill 是工作區中可重複使用的一組工作方法。主要內容放在 `SKILL.md`，也可以附上指令稿、範本和參考資料。

將 skill 加入 [Agent](/agents) 後，Agent 執行相關工作時就會參照其中的指引。你不必把相同方法複製到每個 Agent 的指令中，更新時也只需維護一份。

## skill 與 Agent 指令

| | Agent 指令 | skill |
|---|---|---|
| **適合保存** | 這名 Agent 長期不變的職責、邊界和交付要求 | 某類工作可重用的步驟、資料和工具 |
| **使用範圍** | 只屬於一名 Agent，每次執行都會提供 | 可以加入多名 Agent，並個別啟用或停用 |
| **例子** | "只審查前端程式碼，不直接修改" | 無障礙檢查清單和報告範本 |

## 建立或匯入 skill

在工作區的 **skill** 頁面選擇"新增 skill"，可以使用以下四種方式：

| 方式 | 適用情況 |
|---|---|
| **手動建立** | 從空白的 `SKILL.md` 開始撰寫。 |
| **從本機匯入** | 選取包含 `SKILL.md` 的資料夾，或這台電腦上的 `.skill` / `.zip` 壓縮檔。 |
| **從 URL 匯入** | 從 GitHub、ClawHub 或 Skills.sh 匯入已發布的 skill。 |
| **從執行環境複製** | 掃描已連線電腦上的 skill，並將選取項目複製到工作區。 |

從執行環境複製的是當下的檔案快照。之後本機檔案有變更時，工作區中的版本不會自動更新；請重新匯入，或在 Multica 中編輯。

同一套壓縮檔格式也可以用 CLI 匯入：

```bash
multica skill import --file ./review-helper.skill
```

如果工作區已有同名 skill，匯入時可以取消、覆寫現有內容、另存新名稱或略過。只有 skill 建立者能透過匯入覆寫；即使工作區 `admin` 可以在應用程式中編輯，也不能透過匯入覆寫。若要更新已在工作區中的 skill，請使用[更新已匯入的 skill](#更新已匯入的-skill)。

## 更新已匯入的 skill

從 GitHub、ClawHub 或 Skills.sh 匯入的 skill 會保留來源資訊。若要取得最新版本，請在 skill 頁面按**更新**（或在清單列的選單中選"從來源更新"），也可以使用 CLI：

```bash
multica skill refresh <skill-id>
```

skill 會從來源重新下載，並取代工作區中的版本：

- **保留**：skill 的身分，包括 Agent 指派、標籤、建立者和建立日期。Agent 不必重新加入 skill。
- **取代**：名稱（來源更名時也會更新）、描述、`SKILL.md` 和所有支援檔案。對 skill 所做的本機修改會被覆寫。

skill 建立者以及工作區 `owner`、`admin` 都可以從來源更新。手動建立、從壓縮檔匯入或從執行環境複製的 skill 沒有託管來源，無法用這種方式更新；請重新匯入。

若要一次更新多個 skill，請在清單中選取項目，再從選取工具列按**更新**。所有選取且有託管來源的 skill 都會重新下載；沒有託管來源的項目會略過。

## skill 內容

每個 skill 都有主檔案 `SKILL.md`，請在其中說明：

- skill 適用的情況；
- 開始前需要檢查的項目；
- 執行步驟；
- 結果應以什麼形式交付；
- 哪些情況需要停止並向成員確認。

你也可以加入支援檔案，例如：

```text
SKILL.md
references/api-conventions.md
templates/review-report.md
scripts/check.sh
```

`SKILL.md` 是保留路徑，不能再建立同名支援檔案。支援檔案會和主檔案一起提供給 Agent。

## 加入 Agent

建立或匯入 skill 後，還需要將它加入特定 Agent。你可以在 skill 頁面選擇 Agent，也可以在 Agent 的 **skill** 分頁管理。

- 一個 Agent 可以使用多個 skill；
- 同一個 skill 可以提供給多個 Agent 使用；
- 暫時不需要時，可以停用連結，不必刪除 skill；
- 修改內容會從後續執行開始生效，不會影響已開始的執行。

只有有權修改該 Agent 的成員，才能為它加入、移除或停用 skill。

## 工作區 skill 和儲存庫中的 skill

工作區 skill 儲存在 Multica，適合由團隊共同維護，再加入不同 Agent 使用。

部分 AI 程式開發工具也會直接讀取程式碼儲存庫中的專案層級 skill，例如 `.claude/skills/` 或 `.agents/skills/`。這些檔案仍由儲存庫管理，Multica 不會自動將它們登記為工作區 skill。支援情況依工具而異，請參閱 [AI 程式開發工具對照](/providers)。

連線電腦上已安裝的執行環境本機 skill（Claude Code 和 Codex）會顯示在 Agent 的 **skill** 分頁中，可以針對個別 Agent 停用。停用同樣需要有權修改該 Agent。

## 修改權限

任何工作區成員都可以建立或匯入 skill。建立者和工作區 `owner`、`admin` 可以修改或刪除；其他成員可以查看和使用，但不能覆寫內容。

刪除無法復原，也會同時從所有 Agent 移除該 skill。

<Callout type="warning">
從外部匯入的 skill 可能包含指令稿、命令或不安全指示。Multica 不會替你審查、簽署或隔離這些內容。匯入的內容會原樣交給 Agent，因此請確認來源可信。
</Callout>
