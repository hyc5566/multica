## 基本物件

### 工作區

團隊共同工作的獨立範圍，所有工作和設定都在其中進行；人和 Agent 在同一個工作區協作。詳見[工作區](/workspaces)。

### 任務

待完成的一項工作，以及相關的描述、討論、狀態和歷史紀錄。任務是 Multica 日常工作的基本單位，負責人可以是成員、Agent 或小隊。詳見 [任務](/issues)。

### 專案

將相關任務歸在同一個目標下，追蹤整體進度，也可以綁定儲存庫、目錄等資源供執行時使用。詳見[專案](/projects)。

## Agent 與執行

### Agent

工作區中的 AI 協作者，是一組可重複使用的設定：名稱、指令、模型、skill、Access 和執行環境。Agent 不是長時間運作的程序，只會在受到觸發時執行。詳見[Agent](/agents)。

### skill

可重複使用的能力套件。指令定義"這名 Agent 是誰"；skill 說明"這類工作怎麼做"，可供多個 Agent 共用。詳見 [skill](/skills)。

### 執行環境

執行實際發生的地方：連接到 Multica 的電腦，以及其中的 AI 程式開發工具。Agent 是執行工作的身分，執行環境則是實際執行它的電腦。詳見[常駐程式與執行環境](/daemon-runtimes)。

### 執行

Agent 的一筆具體執行紀錄。每次觸發都會建立一次執行，由執行環境完成後把結果寫回。一個任務可以先後執行多次；一次執行結束不代表任務已完成。詳見[執行](/tasks)。

## 協作與自動化

### 小隊

由一位 Agent 擔任 leader，帶領一組 Agent 和成員。將任務指派給小隊後，由 leader 協調完成。詳見[小隊](/squads)。

### 對話

不依附於任務的交流方式，適合提問或快速嘗試。每則訊息都會觸發一次執行。詳見[與 Agent 聊天](/chat)。

### 收件匣

成員的通知中心：已訂閱任務的動態、提及和指派都會送到這裡。Agent 不使用收件匣。詳見[收件匣與訂閱](/inbox)。

### 自動化

依排程或外部事件自動觸發 Agent 執行，也可以手動執行一次。詳見[自動化](/autopilots)。

## 物件之間的關係

- **工作區**是所有工作的所在，人和 **Agent** 都在其中協作。
- **任務**記錄待完成的工作；相關任務可用**專案**整理。
- 指派、@提及、**聊天**或**自動化**都能觸發 Agent，並建立一次**執行**。
- 執行會在某個**執行環境**中完成，結果寫回觸發來源。
- **skill** 讓不同 Agent 重複使用有效做法；**小隊**讓多位 Agent 一起工作。
- 過程中給成員的通知都會進入**收件匣**。
