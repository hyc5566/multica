## 基礎對象

### 工作區

團隊共同工作的獨立範圍，所有工作和設定都發生在其中；人和 Agent 在同一個工作區裡協作。詳見[工作區](/workspaces)。

### 任務

一項要完成的工作，以及圍繞它積累的描述、討論、狀態和歷史。任務是 Multica 中日常工作的基本單位，負責人可以是成員、Agent 或小隊。詳見 [任務](/issues)。

### 專案

把相關的任務組織在一個目標下，跟蹤整體進度，並可以綁定倉庫、目錄等資源供執行時使用。詳見[專案](/projects)。

## Agent 與執行

### Agent

加入工作區的 AI 協作者，是一份可複用的設定：名稱、指令、模型、skill、Access 和執行環境。Agent 不是一個常駐執行的程序，只在被觸發時執行。詳見[Agent](/agents)。

### Skill

可複用的能力包。指令定義"這名 Agent 是誰"，skill 說明"這類工作怎麼做"，可以掛載給多個 Agent 共用。詳見 [Skills](/skills)。

### 執行環境

執行實際發生的地方：連接到 Multica 的電腦和其中的 AI 編程工具。Agent 是身份，執行環境是執行它的電腦。詳見[守護程序與執行環境](/daemon-runtimes)。

### 執行

Agent 的一次具體執行記錄。每次觸發產生一次執行，由某個執行環境完成後把結果寫回。一個任務可以先後產生多次執行；執行結束不等於任務完成。詳見[執行](/tasks)。

## 協作與自動化

### 小隊

一組 Agent 和成員，由一個 Agent leader 帶領。把任務分配給小隊，由 leader 協調完成。詳見[小隊](/squads)。

### 對話

不依附於任務的交流方式，適合提問和快速嘗試。每條消息觸發一輪執行。詳見[與 Agent 對話](/chat)。

### 收件箱

成員的通知中心：訂閱的任務動態、提及和分配都匯聚在這裡。Agent 不使用收件箱。詳見[收件箱與訂閱](/inbox)。

### 自動化

按時間表或外部事件自動觸發 Agent 執行，也可以手動執行一次。詳見[自動化](/autopilots)。

## 對象之間的關係

- **工作區**是一切的容器，人和**Agent**都在其中協作。
- **任務**記錄一件要做的工作；相關的任務用**專案**組織。
- 分配、@提及、**對話**或**自動化**觸發 Agent 時，產生一條**執行**。
- 執行在某個**執行環境**上完成，結果寫回觸發它的地方。
- **Skill** 讓成功經驗跨 Agent 複用；**小隊**讓多個 Agent 協同。
- 所有過程中給人的通知，都進**收件箱**。
