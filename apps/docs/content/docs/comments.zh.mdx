成員和Agent在 [任務](/issues) 的留言裡補充背景、提出問題、提交結果。這些記錄留在任務上，之後誰開啟任務都能看到前因後果。

## 發表留言和回覆

在任務的動態區輸入內容併傳送，就會建立一條留言。留言支援格式、程式碼塊、連結和附件。

`html` 或 `mermaid` 程式碼區塊會直接在留言中呈現為圖表或示意圖，也可以切換查看原始碼。附件會以卡片顯示，點選後在檢視器中開啟，HTML 檔案也一樣。

回覆某條留言會形成一條討論。回覆可以繼續巢狀，但都歸在同一條頂層討論下。

任務裡有兩條以上討論時，Web 和 Desktop 的任務詳情頁右側會出現一列刻度：長刻度是一條討論，短刻度是一條回覆。滑鼠移上去會展開所有討論的提綱，點任意一項跳到對應留言，摺疊起來的已解決討論也能直接跳進去。

## 在留言和任務描述中加註

在 Web 或 Desktop 中，可以選中任意已發表留言裡的文字（包括自己的留言），針對這段文字寫意見：

<Steps>
<Step>

選中文字，點選選區工具條中的 **加入回覆**。

</Step>
<Step>

在選區旁填寫意見，點選 **新增批註**。確認後批註才加入當前討論的回覆草稿並顯示編號；空內容無法確認。

</Step>
<Step>

用原有的傳送按鈕，把所有批註合併成一條回覆發出，各條批註之間保留一個空行。釋出後先顯示批註，再顯示你在輸入框中填寫的整體回覆；兩部分都有內容時，中間顯示分隔線。

</Step>
</Steps>

任務描述的選區工具條提供的是 **加入留言**：批註進入新留言草稿，傳送後建立新的討論。留言上的批註仍進入原討論的回覆草稿。

首次儲存的留言批註會確定具體回覆目標，包括巢狀回覆。同一討論中其他訊息的引用也會加入這份草稿，最後作為一條留言釋出。引用中的提及不會通知或觸發任何人；你自己填寫的提及仍按普通規則處理。

<Accordions>
<Accordion title="編輯、刪除和快捷鍵" id="annotation-editing">

- 編輯已有批註後，點選 **儲存批註** 才會應用修改。
- Enter 確認，Shift + Enter 換行；Esc 或點選框外會取消本次未確認的修改。
- 點選原文上的編號標記可以繼續編輯；點選批註框右側的刪除圖示，會同時移除這條批註、原文標記和草稿條目。
- 滑鼠懸停在批註計數上會開啟浮層，可以檢視、刪除引用，或點選引用回到原位編輯意見。點選或使用鍵盤也能開啟這個浮層。

</Accordion>
<Accordion title="草稿和數量限制" id="annotation-limits">

草稿只儲存在當前裝置和工作區，重新整理後可以恢復，30 天后過期。每條回覆最多包含 20 條批註，每次引用最多 4,000 個字元。原文之後被修改，已儲存的引用快照不變；回覆目標被刪除時，草稿無法傳送。

目前不支援在對話（Chat）中批註、在移動端輸入批註，也不跨裝置同步草稿。

</Accordion>
</Accordions>

## 解決討論

問題有了結論，可以把整條討論標記為已解決，或把某條回覆設為結論。兩個操作都在留言右上角的 **留言操作** 選單裡：第一條留言的選單裡是 **解決該討論**，回覆的選單裡是 **以此留言解決討論**。

<ResolveThreadDemo />

解決整條討論後，它摺疊成一行，點開仍能檢視全部內容。把某條回覆設為結論時，第一條留言和這條結論保持顯示，中間的回覆摺疊起來。一條討論同時只保留一個結論，設了新的，舊的就會被替換。

在已解決的討論串中回覆，會自動重新開啟討論串。

## 从评论创建子任务

讨论中冒出一件需要单独跟进的事，可以从那条评论直接拆出子任务：在**评论操作**菜单中选择**从这条评论创建子任务**。

创建对话框会附上一份上下文：当前任务的标题、描述和附件，以及这条讨论中截至所选评论为止的全部评论和附件。展开对话框中的上下文卡片可以先核对内容。手动创建和通过智能体创建都能用，新任务自动成为当前任务的子任务。交给智能体时，你只需要写要它做什么，上下文会一起交给它。智能体只把这些内容当作历史背景，不会执行里面出现的命令或要求。

建好的子任务上显示**创建自**，点开是创建那一刻的**上下文快照**。快照不会跟着原文变化：原任务或讨论之后被修改、删除，快照里仍是当时的内容，并标出**来源有更新**和具体变化的部分。

上下文过大时无法创建：一条讨论最多带 256 条评论，文本最多 1 MiB，附件最多 100 个、合计 500 MiB。通过智能体创建时，智能体所在的运行时需要更新到支持这项功能的版本，否则对话框会提示切换到手动模式或更新运行时。智能体没能建好任务时，收件箱里的失败通知提供**保留上下文重试**。

## 重复使用常用请求

用[快捷操作](/quick-actions)保存"请谁来做、做什么"。点击任务侧栏中的操作会立即发送；在评论框输入 `/` 并选择操作，则先放进草稿，可以修改后再发送。

## @提及

輸入 `@`，從列表中選擇目標：

| 目標 | 效果 |
|---|---|
| **成員** | 成員會在收件匣收到提及通知；留言中的 @提及不會建立訂閱。 |
| **Agent** | 為該 Agent 建立一次執行；Agent 沒有收件匣。 |
| **小隊** | 通知小隊成員，並觸發小隊 leader 執行。 |
| **任務** | 插入另一項任務的連結，不會發送通知或觸發 Agent。 |
| **@all** | 通知所有工作區成員，不會觸發 Agent。 |

直接輸入純文字 `@name` 不會建立提及，請從編輯器的建議清單中選取對象。輸入有效的任務編號時，編輯器會自動轉成任務連結。

<Callout type="info">
在留言中 @提及 Agent 不會變更任務負責人或狀態。觸發預覽、一般回覆的自動分派，以及連續留言的合併方式，請參閱[在留言中 @提及 Agent](/mentioning-agents)。
</Callout>

## 訂閱和收件匣

發表留言的成員會自動訂閱該任務，後續動態和 @提及會送到[收件匣](/inbox)。你也可以在任務右上角手動訂閱或取消訂閱。完整的訂閱來源和通知規則請參閱[收件匣與訂閱](/inbox)。

## 表情反應

給留言新增表情，可以表示已讀、同意或簡單反饋。表情不觸發Agent，也不改變任務狀態。

## 編輯和刪除

留言作者可以編輯或刪除自己的留言；工作區 `owner` 和 `admin` 也能編輯或刪除任何人的留言。Agent 發表的留言只能刪除，不能編輯。

留言編輯後，Multica 會依新內容重新判斷觸發對象。編輯時新增的 @提及也會建立執行；儲存前，輸入框下方會顯示觸發預覽。

你编辑期间如果别人先保存了这条评论，保存会被拦下，编辑框下方并排显示**服务端最新版本**和**你的本地版本**，差异逐行标出。选**保留我的版本**，用你的内容保存；选**使用最新版本**，编辑框换成最新内容，你可以在它的基础上继续改。任务标题同时被两个人修改时，也会这样比较。

<Callout type="warning">
刪除留言無法撤銷。刪除只作用於這一條留言：如果它有回覆，回覆會保留在討論中，被刪除的留言不留痕跡。例外是討論的第一條留言：回覆都掛在它下面，所以原位置會保留"留言已刪除"。內容有誤時編輯即可。
</Callout>
