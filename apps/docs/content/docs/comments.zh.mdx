留言是 [任務](/issues) 中持續協作的地方。成員和 Agent 可以在這裡補充背景、提出問題和交付結果；之後重新開啟任務時，仍能看到完整脈絡。

## 發表留言和回覆

在任務動態區輸入內容並送出，即可新增留言。留言支援格式、程式碼區塊、連結和附件。

`html` 或 `mermaid` 程式碼區塊會直接在留言中呈現為圖表或示意圖，也可以切換查看原始碼。附件會以卡片顯示，點選後在檢視器中開啟，HTML 檔案也一樣。

回覆留言會形成討論串。回覆可以繼續巢狀，但都會歸在同一則頂層留言之下。

## 在留言和任務描述中加註

在 Web 或 Desktop 中選取任何已發布留言（包括自己的留言），再從選取工具列按 **加入回覆**。你可以在選取文字旁撰寫註記，再按 **新增註記**，將它加入目前的回覆草稿。只有確認且非空的註記才會顯示數量和來源標記。編輯註記後，按 **儲存註記** 才會套用變更。按 Enter 確認、Shift + Enter 換行；按 Escape 或點選框外會取消尚未確認的變更。點選原文上的編號標記可再次編輯；點選註記旁的垃圾桶按鈕，則會直接移除原文註記、反白標記和草稿項目。將滑鼠移到註記數量上，可在浮動面板中檢視或移除引用；也可點選引用，回到原文編輯註記。你也可以點選面板或使用鍵盤開啟。按原有的送出按鈕即可將所有內容合併為一則回覆，各則註記之間會保留一個空行。發布後會先顯示註記，再顯示你撰寫的整體回覆；兩部分都有內容時，中間會加上分隔線。任務描述的選取工具列提供 **加入留言**；描述註記會加入新留言草稿，並以新討論串送出。留言註記則留在原討論串的回覆草稿中。

留言註記第一次儲存時，就會固定回覆目標，包括巢狀回覆。同一討論串中其他訊息的引用也會加入這份草稿。按原有送出按鈕，即可將全部內容作為一則留言發布。引用中的 @提及不會通知或觸發任何人；你自行輸入的 @提及仍依一般規則處理。

草稿只會保存在目前的裝置和工作區，重新載入後仍可還原，並會在 30 天後過期。每則回覆最多可加 20 則註記，每則引用最多 4,000 個字元。來源內容變更後，已儲存的引用仍會保留；若回覆目標已刪除，就無法送出。此功能不包含 Chat、行動版註記輸入或跨裝置草稿同步。

## 解決討論

問題有結論後，可以將整個討論串標記為已解決，或將其中一則回覆設為結論；每個討論串一次只能有一個結論。已解決的討論串會收合，但仍可展開查看。

在已解決的討論串中回覆，會自動重新開啟討論串。

## @提及

輸入 `@`，從列表中選擇目標：

| 目標 | 效果 |
|---|---|
| **成員** | 成員會在收件匣收到提及通知；留言中的 @提及不會建立訂閱。 |
| **Agent** | 為該 Agent 建立一次執行；Agent 沒有收件匣。 |
| **小隊** | 通知小隊成員，並觸發小隊 leader 執行。 |
| **任務** | 插入另一項任務的連結，不會發送通知或觸發 Agent。 |
| **@all** | 通知所有工作區成員，不會觸發 Agent。 |

直接輸入純文字 `@name` 不會建立提及，請從編輯器的建議清單中選取對象。輸入有效的任務編號時，編輯器會自動轉成任務連結。

<Callout type="info">
在留言中 @提及 Agent 不會變更任務負責人或狀態。觸發預覽、一般回覆的自動分派，以及連續留言的合併方式，請參閱[在留言中 @提及 Agent](/mentioning-agents)。
</Callout>

## 訂閱和收件匣

發表留言的成員會自動訂閱該任務，後續動態和 @提及會送到[收件匣](/inbox)。你也可以在任務右上角手動訂閱或取消訂閱。完整的訂閱來源和通知規則請參閱[收件匣與訂閱](/inbox)。

## 表情反應

在留言上加表情符號，可表示已讀、同意或快速回饋。表情符號不會觸發 Agent，也不會變更任務狀態。

## 編輯和刪除

留言作者可以編輯或刪除自己的留言；工作區 `owner` 和 `admin` 也能編輯或刪除任何人的留言。Agent 發表的留言只能刪除，不能編輯。

留言編輯後，Multica 會依新內容重新判斷觸發對象。編輯時新增的 @提及也會建立執行；儲存前，輸入框下方會顯示觸發預覽。

<Callout type="warning">
刪除留言無法復原，而且只會刪除該則留言。如果留言已有回覆，回覆會留在討論串中，被刪除的留言不會留下痕跡。例外是開啟討論串的第一則留言：因為回覆隸屬於它，原位置會保留"此留言已刪除"的提示。內容有誤時請直接編輯。
</Callout>
