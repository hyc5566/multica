如果工作還沒形成明確任務，可以先透過聊天整理想法、查詢工作區資訊、討論做法，或請 Agent 先完成一項小工作。

**Chat 是你和 [Agent](/agents) 的一對一聊天**，不屬於 [任務](/issues) 看板。Agent 預設**不會取得任何任務脈絡**，不會查看看板，也不會自行把聊天內容轉成任務。整段聊天**只有你看得到**，[工作區](/workspaces)中的其他人（包括 admin）都無法查看。適合和 Agent 討論做法、腦力激盪，或詢問與任何任務無關的問題。

Chat **不會綁定任何任務**：Agent 不會自動收到任務說明或留言，但仍可在權限範圍內使用 Multica CLI 查詢工作區、專案、任務和 skill。

Chat 也可以附帶背景資訊。點選輸入框左下角的 **+**，選擇**專案脈絡**，將[專案](/projects)加入聊天；Agent 執行時會取得該專案的描述、儲存庫和其他資源。

## 開始對話

1. 在側邊欄開啟 **Chat**。
2. 點選新增，選擇你有權執行的 Agent。
3. 輸入訊息，也可以附加圖片或檔案。
4. 送出後，Multica 會為這則訊息建立一次執行，並將回覆送回目前的聊天。

執行環境離線時，訊息會等到環境重新上線。Agent 遭封存，或你失去執行權限後，就無法再傳送新訊息。

傳送第一則訊息前，Chat 會顯示所選 Agent 設定的最多三個建議。選取建議會將完整提示填入輸入框，但不會送出，你可以先調整內容。未設定建議的 Agent 會使用在地化的通用範例。

## 對話與任務的選擇

| 需要 | 更適合 |
|---|---|
| 快速提問、討論做法或處理私人草稿 | **Chat** |
| 需要明確負責人、狀態、優先順序和交付成果 | **任務** |
| 需要團隊成員查看背景並接續討論 | **任務** |
| 暫時查詢工作區資訊，不需要留下工作紀錄 | **Chat** |

在 Multica 中建立的直接聊天只有建立者能查看，其他工作區成員和管理員都無法讀取。需要團隊共同掌握的結論，請整理到任務、專案描述或 skill 中。

## 多輪上下文

系統會盡量在 AI 程式開發工具中延續同一個工作階段，因此後續訊息不必重複先前內容。Multica 會保存工作階段 ID，並將後續執行交給能存取該工作階段的執行環境。

如果本機工作階段已不存在、無法延續脈絡，或不應沿用上次的錯誤，執行環境就會開啟新的工作階段。聊天中的歷史訊息仍會保留。

## 查看和停止執行

Agent 執行時，介面會顯示目前階段和工具活動。展開**查看詳細資訊**可以檢視完整執行過程。

若要中斷，請點選輸入框旁的停止按鈕。已顯示在聊天中的內容會保留；尚未處理的輸入則會盡可能還原到編輯框。

## 整理對話列表

Chat 支援重新命名、釘選、封存和刪除：

- **釘選**會將常用聊天固定在清單前方；
- **封存**會將聊天移至"已封存"並設為唯讀；
- **取消封存**後即可繼續傳送訊息；
- **刪除**會永久移除聊天及其中的訊息。

若 Chat 綁定外部管道（例如 Slack），封存時會解除綁定；取消封存不會重新綁定，必須再次連結。

<Callout type="warning">
刪除 Chat 無法復原，並會停止其中尚未完成的執行。暫時不需要時，請改用封存。
</Callout>
