對話適合還沒有形成明確任務的工作：梳理想法、查詢工作區情況、討論方案，或者先讓 Agent 完成一個小任務。

**對話（Chat）是你和 [Agent](/agents) 的一對一獨立溝通**——跳出 [任務](/issues) 看板。Agent 預設**沒有任何任務上下文**——它不盯著你的看板，也不會自己把對話變成任務——整段對話**完全私人**（[工作區](/workspaces) 裡其他人、包括 admin 都看不到）。適合和 Agent 討論方案、做 brainstorming、問一個不屬於任何任務的問題。

對話**不綁定某一條任務**：Agent 不會自動收到任務的描述和留言，但仍可以在權限範圍內用 Multica CLI 查詢工作區、專案、任務和 skill。

對話也可以攜帶背景。點擊輸入框左下角的 **+**，選擇**專案上下文**，為對話掛上一個[專案](/projects)；Agent 執行時會收到該專案的描述和倉庫等資源。

## 開始對話

1. 開啟側邊欄中的**對話**。
2. 點擊新建，選擇一個你有權執行的 Agent。
3. 輸入消息，也可以附加圖片或檔案。
4. 傳送後，Multica 會為這條消息建立一次執行，回覆會回到當前對話。

執行環境離線時，消息會等待它重新上線。Agent 被歸檔，或者你失去調用權限後，不能繼續傳送新消息。

第一條消息傳送前，對話頁會顯示所選 Agent 設定的最多三個建議。選擇後會把完整提示詞填入輸入框而不會傳送，方便你先調整。未設定建議的 Agent 會使用本地化的通用示例。

## 對話與任務的選擇

| 需要 | 更適合 |
|---|---|
| 快速提問、探索方案或處理私人草稿 | **對話** |
| 明確負責人、狀態、優先順序和交付結果 | **任務** |
| 讓團隊成員查看背景並繼續討論 | **任務** |
| 臨時查看工作區資訊，不需要建立工作記錄 | **對話** |

在 Multica 中建立的直接對話只對建立者開放，其他工作區成員和管理員不能讀取。需要團隊共同查看的結論，應整理到任務、專案說明或 skill 中。

## 多輪上下文

同一段對話會盡量繼續 AI 編程工具中的原會話，因此後續消息不需要重複前面的內容。Multica 會儲存會話標識，並把後續執行路由到能夠訪問該會話的執行環境。

如果本地會話已經不存在、上下文無法繼續，或者上一次錯誤不適合複用，執行環境會從新會話開始。對話中的歷史消息仍然保留。

## 查看和停止執行

Agent 執行環境，介面會顯示當前階段和工具活動。展開**查看詳情**可以檢查更完整的執行過程。

需要中斷時，點擊輸入框旁的停止按鈕。已經返回到對話中的內容會保留；尚未開始處理的輸入會盡量恢復到編輯框中。

## 整理對話列表

對話支援重命名、置頂、歸檔和刪除：

- **置頂**把常用對話固定在列表前面；
- **歸檔**把對話移到"已歸檔"並設為只讀；
- **取消歸檔**後可以繼續傳送消息；
- **刪除**會永久移除對話及其中的消息。

如果對話綁定了外部渠道（如 Slack），歸檔時綁定會斷開，取消歸檔不會恢復，需要重新綁定。

<Callout type="warning">
刪除對話無法撤銷，並會停止其中尚未結束的執行。暫時不需要時用歸檔。
</Callout>
