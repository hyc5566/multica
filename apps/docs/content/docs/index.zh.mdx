## Multica 可以做什麼

- **交付工作給 Agent**：像指派工作給同事一樣交辦任務，Agent 會更新進度並交付結果。
- **共享工作資訊**：討論、紀錄和成果都留在工作區，團隊成員隨時都能查看。
- **讓工作自動執行**：設定排程，讓多個 Agent 自動協作。
- **累積團隊經驗**：將有效做法儲存為 skill，供所有 Agent 重複使用。
