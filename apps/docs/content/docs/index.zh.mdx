## Multica 可以做什麼

- **把工作交給Agent**：像分配給同事一樣分配任務，它會更新進度、提交結果。
- **共享上下文**：任務裡的討論、記錄和產出都留在工作區，團隊成員都能看到。
- **讓工作自動運轉**：用自動化定期啟動Agent，多個Agent還可以組成小隊協作。
- **沉澱團隊經驗**：把有效的做法存成 skill，掛載給多個Agent複用。
