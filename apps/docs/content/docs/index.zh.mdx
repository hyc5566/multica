## Multica 能做什麼

- **把工作交給 Agent**：像分配給同事一樣分配任務，它會更新進度、提交結果。
- **共享全部上下文**：討論、記錄和產出都留在工作區，團隊成員隨時可見。
- **讓工作自動運轉**：設定定時任務，讓多個 Agent 自動協作。
- **沉澱團隊經驗**：把有效的做法存成 skill，供所有 Agent 複用。
