<Callout type="info">
Agent 開始執行前，所在電腦至少要安裝並登入一款[受支援的 AI 程式開發工具](/providers)，例如 Claude Code、Codex 或 Cursor。Multica 不會附帶這些工具。
</Callout>

## 1. 登入並進入工作區

使用 Web（[multica.ai](https://multica.ai)）或 [Multica Desktop](https://multica.ai/download) 登入，可使用電子郵件驗證碼或 Google 帳號。

- **Desktop**：可以自動連接這台電腦。
- **Web**：需要在下一步透過命令列連線。

## 2. 連接一台電腦

Agent 會在你連接的電腦上執行工作。開啟側邊欄底部的 **設定 → 執行環境**：

- **使用 Desktop**：Desktop 會自動將這台電腦註冊為執行環境，並偵測已安裝的 AI 程式開發工具。若剛安裝工具，請點選"重新整理"再次偵測。
- **使用 Web，或要新增另一台電腦**：點選右上角的 **新增電腦**，並在目標電腦的終端機中執行對話框提供的兩個命令：

 **macOS / Linux**

 ```bash
 curl -fsSL https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.sh | bash
 multica setup
 ```

 **Windows PowerShell**

 ```powershell
 irm https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.ps1 | iex
 multica setup
 ```

 `multica setup` 會開啟瀏覽器完成登入，接著在背景啟動常駐程式。常駐程式上線後，對話框通常會在一分鐘內偵測到這台電腦。

**確認成功**：執行環境清單中出現一台在線電腦。

![Add a computer 彈窗：兩條命令與等待檢測提示](/images/docs/quickstart-add-computer.webp)

<Callout type="info">
自架執行個體的連線命令略有不同，請見[自架快速上手](/self-host-quickstart)。
</Callout>

## 3. 建立一個 Agent

開啟側邊欄中的 **工作區 → Agent**，點選 **新增 Agent**，再選擇建立方式：

- **從空白開始**：自行填寫欄位。只需提供名稱，再確認執行環境和 AI 程式開發工具即可建立。
- **使用 AI 建立**：描述你的需求，Agent Builder 會提問並產生設定。這種方式需要有一個在線的執行環境。

其他設定之後還能調整，詳見[建立和設定 Agent](/agents-create)。

**確認成功**：Agent 清單中出現你的 Agent，且狀態為在線。

![建立 Agent 的起點選擇頁：Start blank 與 Build with AI](/images/docs/quickstart-new-agent.webp)

## 4. 指派第一個任務

點選側邊欄頂端的 **新增任務**（或按 `C`）。在預設的 Agent 模式下：

1. 在 **建立者** 中選擇剛建立的 Agent；
2. 用一兩句話描述工作內容，例如"介紹一下這個工作區可以怎麼使用"；
3. 送出後，Multica 會建立任務、將 Agent 設為負責人，並立即開始執行。

![新建任務彈窗的 Agent 模式：Created by 已選中 Multica Assistant](/images/docs/quickstart-new-issue.webp)

## 5. 查看進度和結果

送出後開啟這項任務：執行記錄會顯示執行狀態，Agent 的進度和回覆會出現在時間軸中。

**確認成功**：執行記錄狀態變成"已完成"，且時間軸中出現 Agent 的回覆。點選"查看逐字稿"可檢視完整內容。

![任務中 Agent 的回覆與已完成的執行日誌](/images/docs/quickstart-run-result.webp)

## 常見問題

| 現象 | 先檢查什麼 |
|---|---|
| 找不到執行環境 | 確認 AI 程式開發工具已安裝，且能在終端機中執行。Desktop 使用者請點選"重新整理"；使用 CLI 時請重新執行 `multica setup`。 |
| 執行環境顯示離線 | 保持 Desktop 開啟；若使用 CLI，請執行 `multica daemon status`，若常駐程式未啟動則執行 `multica daemon start`。 |
| 任務持續排隊 | 確認 Agent 使用的執行環境在線。執行環境達到並行上限時，新的執行會繼續排隊。 |

更多情況請參閱[疑難排解](/troubleshooting)。
