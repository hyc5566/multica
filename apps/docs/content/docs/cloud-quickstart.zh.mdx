<Callout type="info">
Agent 執行前，執行它的電腦上需要有至少一款已安裝並登入的[支援的 AI 編程工具](/providers)，例如 Claude Code、Codex 或 Cursor。Multica 不自帶這些工具。
</Callout>

## 1. 登入，進入工作區

用 Web（[multica.ai](https://multica.ai)）或 [Multica Desktop](https://multica.ai/download) 登入，支援電子郵件驗證碼和 Google。

- **Desktop**：可以自動連接這臺電腦。
- **Web**：需要在下一步通過命令列連接。

## 2. 連接一臺電腦

Agent 在你連接的電腦上執行工作。開啟側邊欄底部的 **設定 → 執行環境**：

- **用 Desktop**：Desktop 會自動把這臺電腦註冊為執行環境，並檢測已安裝的 AI 編程工具。剛安裝的工具，點"刷新"重新檢測。
- **用 Web，或需要新增另一臺電腦**：點右上角的 **新增電腦**，在目標電腦的終端裡執行彈窗給出的兩條命令：

 **macOS / Linux**

 ```bash
 curl -fsSL https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.sh | bash
 multica setup
 ```

 **Windows PowerShell**

 ```powershell
 irm https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.ps1 | iex
 multica setup
 ```

 `multica setup` 會開啟瀏覽器完成登入，然後讓守護程序在後臺執行。守護程序上線後，彈窗通常在一分鐘內自動檢測到這臺電腦。

**成功標誌**：執行環境列表裡出現一臺在線的電腦。

![Add a computer 彈窗：兩條命令與等待檢測提示](/images/docs/quickstart-add-computer.webp)

<Callout type="info">
自託管實例的連接命令略有不同，見[自託管快速上手](/self-host-quickstart)。
</Callout>

## 3. 建立一個 Agent

開啟側邊欄的 **工作區 → Agent**，點 **新建 Agent**，選擇一條路徑：

- **從空白開始**：自己填欄位。最少只需要名稱，再確認執行環境和 AI 編程工具即可建立。
- **通過 AI 建立**：描述你想要什麼，由 Agent Builder 提問並生成設定。這條路徑需要一個在線執行環境。

其餘設定可以之後完善，詳見[建立和設定 Agent](/agents-create)。

**成功標誌**：Agent 列表中出現你的 Agent，並顯示為在線。

![建立 Agent 的起點選擇頁：Start blank 與 Build with AI](/images/docs/quickstart-new-agent.webp)

## 4. 把第一個任務交給它

點側邊欄頂部的 **新建任務**（或按快捷鍵 `C`）。在預設的 Agent 模式下：

1. 在 **建立者** 中選擇剛建立的 Agent；
2. 用一兩句話描述要做的事，例如"介紹一下這個工作區可以怎麼用"；
3. 提交。Multica 會建立任務、把 Agent 設為負責人並立即開始執行。

![新建任務彈窗的 Agent 模式：Created by 已選中 Multica Assistant](/images/docs/quickstart-new-issue.webp)

## 5. 查看進度和結果

提交後開啟這條任務：執行日誌顯示執行狀態，Agent 的進展和回覆出現在時間線中。

**成功標誌**：執行日誌狀態變為"已完成"，時間線中出現 Agent 的回覆。需要查看完整過程時，點"查看記錄"。

![任務中 Agent 的回覆與已完成的執行日誌](/images/docs/quickstart-run-result.webp)

## 常見問題

| 現象 | 先檢查什麼 |
|---|---|
| 沒有找到執行環境 | 確認 AI 編程工具已經安裝並能在終端中執行。Desktop 點"刷新"；CLI 方式重新執行 `multica setup`。 |
| 執行環境顯示離線 | Desktop 保持開啟；CLI 方式執行 `multica daemon status`，未啟動時執行 `multica daemon start`。 |
| 任務一直排隊 | 確認 Agent 使用的執行環境在線。執行環境達到併發上限時，新執行會繼續排隊。 |

更多情況見[故障排查](/troubleshooting)。
