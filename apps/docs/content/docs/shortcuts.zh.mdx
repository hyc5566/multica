## 搜尋

按 `⌘K`，或者點應用側欄中的**搜索...**，打開搜索框。不輸入時，這裡列出**新建任務**和你最近打開過的任務。輸入關鍵詞後，結果分組顯示：

| 分組 | 能找到什麼 |
|---|---|
| **頁面** | 收件匣、聊天、任務、專案、Agent、設置等工作區頁面。中文名稱可以用拼音搜，例如輸入 `renwu` 找到"任務"。 |
| **視圖** | 按名稱查找內置任務視圖和你有權訪問的已保存視圖。 |
| **命令** | 新建任務、新建專案，切換淺色、深色主題或跟隨系統主題。打開任務詳情時還有複製任務連結、複製標識符、收起全部評論、展開全部評論。 |
| **成員** | 按姓名或郵箱查找，中文姓名同樣支援拼音。 |
| **工作區** | 你加入的其他工作區，選中後切換過去。 |
| **專案**、**任務** | 匹配標題，也匹配專案說明、任務描述和評論。命中的片段顯示在結果下方；已完成的任務也會出現。 |
| **已取消** | 已取消的專案和任務統一排在最後，不會擠到前面。 |
| **交給Agent** | 有輸入時固定顯示在最後一行。選中後打開**通過Agent建立**，預填你輸入的內容、目前專案，並把目前打開的任務設為父任務；在彈窗里確認後才會建立。 |

選中結果後直接跳轉。按住 `⌘`（Windows / Linux：`Ctrl`）再點選或按回車，會在新分頁裡開啟。按 `Esc` 關閉搜尋框。

## 鍵盤快捷鍵

| 操作 | macOS | Windows / Linux | 說明 |
|---|---|---|---|
| 打開搜索 | `⌘K` | `Ctrl+K` | |
| 新建任務 | `C` | `C` | 打開你常用的建立方式。在專案頁按，新任務會預先填好這個專案。 |
| 顯示或隱藏左側邊欄 | `⌘B` | `Ctrl+B` | |
| 顯示或隱藏右側邊欄 | `⌘/` | `Ctrl+/` | 只在有右側欄的頁面可用，例如任務詳情。 |
| 顯示或隱藏聊天窗 | `⌘J` | `Ctrl+J` | 打開時光標落在輸入框里。見[懸浮聊天窗](/chat#在任意頁面開啟懸浮聊天窗)。 |
| 問 Multica | `⇧⌘J` | `Ctrl+Shift+J` | 在懸浮聊天窗里開始新對話。 |
| 在任務中查找 | `⌘F` | `Ctrl+F` | 見下文。 |
| 歸檔通知 | `E` | `E` | 在從收件匣打開的任務上，歸檔它的通知並打開下一條；查看已歸檔時則取消歸檔目前打開的通知。見[收件匣](/inbox#處理通知)。 |
| 延後通知 | `H` | `H` | 在從收件匣打開的任務上，延後它並打開下一條；已延後的任務則讓它現在回來。 |
| 發送 | `⌘↵` | `Ctrl+Enter` | 發送評論和聊天訊息，也用於提交新任務。 |
| 語音輸入 | 未設置 | 未設置 | 僅 Desktop；先在設置 → 語音輸入中開啟。見[語音輸入](/desktop-app#語音輸入)。 |
| 後退 | `⌘[` | `Ctrl+[` | |
| 前進 | `⌘]` | `Ctrl+]` | |

單鍵快捷鍵（`C`、`E`、`H`）和後退、前進在輸入框里不起作用，避免打字時誤觸。

**導航**類操作還有前往收件匣、聊天、我的任務、任務、專案、自動化、Agent、小隊、統計、執行環境、Skills 和設置，預設都沒有設置按鍵，需要時自己綁定。前往收件匣打開的是收件匣頁面，通知列表本身是工作面板里的一個分區，就在固定下面。前往我的任務打開的是"我的任務"頁面，和工作面板里的**我的工作**視圖不是一回事。

### 固定的系統快捷鍵

下面這些不能修改。除了 `Esc`，其餘只在[桌面版](/desktop-app)有效；網頁版裡這些按鍵由瀏覽器處理。

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 開啟設定 | `⌘,` | `Ctrl+,` |
| 關閉目前分頁 | `⌘W` | `Ctrl+W` |
| 選擇第 1–8 個分頁 | `⌘1`–`⌘8` | `Ctrl+1`–`Ctrl+8` |
| 選擇最後一個分頁 | `⌘9` | `Ctrl+9` |
| 放大 / 縮小 / 重置縮放 | `⌘+` / `⌘−` / `⌘0` | `Ctrl++` / `Ctrl+-` / `Ctrl+0` |
| 關閉對話方塊或選單 | `Esc` | `Esc` |

## 修改快捷鍵

<Steps>
<Step>

開啟**設定 → 快捷鍵**。操作多時，用頂部的搜尋框按名稱查詢。

</Step>
<Step>

點選某個操作右側的按鍵，看到"請按鍵"後按下新的組合。`Esc` 取消，`Delete` 清除這個操作的按鍵。

</Step>
<Step>

每行右側的兩個按鈕分別把這一項恢復預設、停用這一項。頂部的**恢復預設設定**會一次撤銷所有自訂。

</Step>
</Steps>

快捷鍵只儲存在目前裝置上。換一臺電腦，或者從瀏覽器換到桌面版，需要重新設定。

錄入時會拒絕幾類組合，並在按鍵下方說明原因：

- 已經分給其他操作的組合。
- 瀏覽器、桌面窗口或系統佔用的組合，例如 `⌘W`、`⌘R`、`⌘Q`、`⌘,`、複製粘貼這類編輯鍵、`⌘0`–`⌘9` 和縮放鍵。網頁版里 `⌘P`、`⌘L`、`⌘T`、`⌘N`、`⌘D`、`⌘U` 也不能用，桌面端可以。Windows 和 Linux 上帶 Win / Super 鍵的組合都不能用。
- 打開搜索、聊天窗、在任務中查找這類在輸入框里也生效的操作，必須帶 `⌘`、`Ctrl` 或 `Control`，否則打字時會誤觸。 語音輸入還允許 `Option` / `Alt` 加 `Space` 等不輸入文字的按鍵，但不能使用已被佔用的組合。
- **發送**只能是 `↵` 或 `⌘↵`。

<Callout>
把**傳送**改成 `↵` 後，換行改用 `Shift+Enter`：它會插入新段落、繼續列表，或者在程式碼塊裡換行。
</Callout>

## 在任務中查詢

在任務詳情頁按 `⌘F`，開啟的是 Multica 自己的查詢欄，不是瀏覽器的查詢。瀏覽器查詢只能找到已經滾動到螢幕上的評論；這裡會把整條時間線都納入查詢，包括標題、描述和所有評論。

查詢不區分大小寫，查詢欄顯示"目前 / 總數"，沒有結果時顯示"無匹配結果"。按 `↵` 跳到下一個，`Shift+Enter` 跳到上一個，`Esc` 關閉。一段文字中間跨了格式（例如一半加粗）時，查不到這段。

在桌面版，只有目前顯示的分頁會響應 `⌘F`。

## 偏好設定

個人偏好在**設定 → 偏好設定**裡，改動立即生效。各組的儲存範圍不同：

| 分組 | 設定 | 儲存在 |
|---|---|---|
| **語言與地區** | 語言：English、中文、한국어、日本語、Français。切換後頁面會重新載入。<br />時區：預設跟隨瀏覽器；用於所有工作區的日期和圖表，可以搜尋全部時區。 | 帳號，其他裝置同步 |
| **外觀** | 在單獨的 **設定 → 外觀** 頁面：模式（淺色、深色、跟隨系統）、主題、字型和佈局。也可以在搜尋框裡輸入"主題"切換模式。見 [主題與外觀](/themes)。 | 目前裝置 |
| **評論與聊天** | **固定底部評論欄**：開啟時，閱讀很長的時間線也能隨時看到評論框。<br />**回覆正在執行的 Agent 時**：預設"插話到目前執行"還是"本輪結束後開始"，傳送前每條訊息仍可單獨改，見[給正在執行的 Agent 插話](/mentioning-agents#給正在執行的agent插話)。<br />**懸浮聊天窗**：關閉後，底部狀態列裡不再有快捷聊天（窄視窗也不再顯示右下角的圓形聊天按鈕）。 | 目前裝置 |
| **開啟任務** | 點選卡片或行時開啟詳情頁還是懸浮預覽。按住 Shift 點選會開啟另一種。 | 目前裝置 |
| **建立任務時顯示的欄位** | 分別為"Agent 建立"和"手動建立"選擇工具欄上常駐的欄位。隱藏的欄位仍可從 ⋯ 選單使用，有值時自動顯示。 | 目前裝置上的目前工作區 |
