Multica iOS 用戶端目前尚未上架 App Store。你可以在 Mac 上從公開的原始碼儲存庫建置 Release 版本，再安裝到自己的 iPhone。目前尚未提供 Android 用戶端。

安裝後的 App 預設連線至 Multica Cloud，使用既有帳號即可登入。工作區、任務、留言和執行記錄都儲存在伺服器端，不需要從 Web 或 Desktop 手動同步。

## 準備工作

你需要：

- 一台安裝了 Xcode 的 Mac；
- 已在 **Xcode → Settings → Accounts** 登入的 Apple ID；
- 一台透過 USB 連接的 iPhone；
- 在 iPhone 的**設定 → 隱私權與安全性**中開啟開發者模式；
- Node.js、pnpm 和 Git。

如果尚未設定 Xcode 或實機開發環境，請先完成 Expo 的 [iOS 裝置環境設定](https://docs.expo.dev/get-started/set-up-your-environment/)。

## 安裝到 iPhone

複製儲存庫並安裝相依套件：

```bash
git clone https://github.com/multica-ai/multica.git
cd multica
pnpm install
```

接著在儲存庫根目錄執行：

```bash
pnpm ios:mobile:device:prod:release
```

這會建置不依賴 Metro 的 Release 版本，並安裝到已連接的 iPhone。首次建置時會下載 iOS 相依套件並編譯 React Native；之後的建置會沿用 Xcode 快取。

如果 iPhone 阻止 App 開啟，請前往**設定 → 一般 → VPN 與裝置管理**，信任相應的開發者憑證。

## 免費簽章的 7 天限制

使用免費 Apple ID 簽署的 App 只能使用 7 天。到期後，將 iPhone 重新連接至 Mac，再次執行相同的建置命令即可重新簽署。

使用 Apple Developer Program 帳號簽署的版本有效期較長，也可用於 TestFlight 和正式發布。無論採用哪種簽署方式，重新安裝或重新簽署都不會遺失伺服器端資料。

## 簽章失敗

如果 Xcode 顯示 `No matching provisioning profiles found`，預設的 bundle identifier 可能不屬於你的 Apple ID。請改用自己持有的反向網域名稱，再重新建置：

```bash
export EXPO_BUNDLE_IDENTIFIER_PROD=com.yourname.multica
pnpm ios:mobile:device:prod:release
```

這個值只要能在你的 Apple Developer team 中使用即可，不會影響 Multica 帳號或工作區。

## 更新

iOS 自行安裝的版本不會自動更新。請取得最新程式碼、更新相依套件，再重新建置：

```bash
git pull --ff-only
pnpm install
pnpm ios:mobile:device:prod:release
```

## 連接自架實例

Release 建置會將 API 位址寫入 App。`apps/mobile/.env.production` 已提交至儲存庫，預設指向 multica.ai 的公開後端，因此直接複製儲存庫即可建置正式版。

若要連線至自架執行個體，請將 `apps/mobile/.env.production.example` 複製為 `apps/mobile/.env.production.local`，再修改副本：

```dotenv
EXPO_PUBLIC_API_URL=https://api.example.com
EXPO_PUBLIC_WEB_URL=https://app.example.com
```

`.local` 檔案會逐一覆寫儲存庫中已提交的預設值，且已列入 gitignore，因此個人 API 位址不會提交到儲存庫。`EXPO_PUBLIC_API_URL` 為必填；`EXPO_PUBLIC_WEB_URL` 供"Copy link"、"Open on web"等功能使用。請在副本中設定這兩個值：未設定的 key 會沿用 multica.ai 的預設值，這些功能便會開啟 multica.ai，而非你的執行個體。

修改後請重新執行建置命令。iPhone 必須能連線至這個 API 位址；若使用區域網路位址，請勿填入 `localhost`，因為在 iPhone 上它會指向手機本身。

<Callout type="warning">
直接修改 `.env.production` 會變更目前 checkout 的正式環境設定。個人設定請放在已列入 gitignore 的 `.env.production.local`。
</Callout>

如需開發行動版、使用 Simulator 或連線至 staging，請參閱儲存庫中的 [`apps/mobile/README.md`](https://github.com/multica-ai/multica/blob/main/apps/mobile/README.md)。
