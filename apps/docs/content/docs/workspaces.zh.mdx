工作區是 Multica 最上層的隔離範圍。成員、任務、專案、Agent、skill 和執行紀錄都隸屬於單一工作區，與其他工作區完全隔離。

## 工作區的組成

| 類別 | 內容 |
|---|---|
| **工作** | 任務、專案、留言、附件、執行紀錄 |
| **團隊** | 成員、角色、邀請 |
| **Agent** | Agent 設定、skill、執行環境、自動化 |
| **共用設定** | 上下文、標籤、自訂屬性、整合 |

**上下文**會提供給工作區中的每個 Agent，適合記錄團隊背景、產品慣例和長期要求。單次執行的要求則寫在對應任務中。

## 建立工作區

建立工作區時需要填寫三項：

- **名稱**：會顯示給成員，之後可以修改。
- **工作區 URL**：網址中的 slug，例如 `multica.ai/my-team` 裡的 `my-team`。只能使用小寫英文字母、數字和連字號，不能與既有工作區或保留網址重複，建立後無法修改。
- **任務編號前綴**：會依工作區 URL 預先填入，建立前可以修改。以前綴 `MUL` 為例，任務編號會是 `MUL-1`、`MUL-2`，並在工作區內獨立遞增。只能使用大寫英文字母和數字，最多 10 個字元；之後也可以在設定中修改。

建立者會自動成為 `owner`。

## 修改設定

`owner` 和 `admin` 可以修改名稱、圖示、描述、上下文和任務編號前綴；`member` 只能查看。

![工作區設定：名稱、上下文、slug、任務編號前綴與危險區](/images/docs/workspace-settings.webp)

<Callout type="warning">
修改任務編號前綴後，所有任務都會立即改用新編號（`MUL-5` 變為 `NEW-5`），但 PR、分支名稱和聊天紀錄中的舊編號不會更新。
</Callout>

## 切換和離開

同一個帳號可以加入多個工作區。切換工作區只會改變目前查看的內容，不會移動資料。

離開工作區後，必須重新接受邀請才能返回。離開時也會停用你擁有的執行環境、封存綁定在這些環境上的 Agent，並取消尚未完成的執行。

最後一位 `owner` 無法離開；請先將另一位成員升為 `owner`。

## 刪除工作區

只有 `owner` 可以刪除工作區。刪除會永久移除其中所有工作、成員、Agent 設定和執行紀錄，且無法復原。如果只是暫時離開，請選擇離開工作區。
