Agent 是 [Multica 工作區](/workspaces)中的協作者。你可以將任務指派給它、在留言中 @提及它，或直接和它聊天。Agent 會透過綁定的執行環境呼叫 AI 程式開發工具，並把進度和結果寫回工作區。

Agent 本身不是持續執行的程序，而是一組可重複使用的身分和設定；收到工作時才會建立具體的[執行](/tasks)。

## Agent 設定

| 設定 | 說明 |
|---|---|
| **名稱、頭像和描述** | 讓團隊了解 Agent 的身分和擅長的工作。描述只供顯示，不會放進執行提示。 |
| **指令** | 說明職責、工作方式、界線和交付要求，每次執行都會使用。 |
| **對話開場建議** | 提供最多三個 Agent 專屬範例，顯示在新聊天畫面。選取後只會填入輸入框，不會送出。 |
| **skill** | 提供可重複使用的方法、參考資料和支援檔案。 |
| **執行環境、模型和思考強度** | 決定使用哪個執行環境、AI 程式開發工具和模型；部分工具（例如 Codex）也提供服務層級選項。 |
| **Access** | 決定哪些成員可以執行這個 Agent。 |
| **執行設定** | 包括並行數上限、環境變數、CLI 參數、MCP 和外部整合。 |

更換模型或修改指令不會建立新的 Agent，過去的任務、留言和執行紀錄也會保留。

## Agent、執行環境和執行

| 概念 | 職責 |
|---|---|
| **Agent** | 決定由誰工作，以及如何進行 |
| **執行環境** | 決定由哪台電腦和哪款 AI 程式開發工具執行 |
| **執行** | 記錄一次執行的過程和結果 |

一個執行環境可以執行多個 Agent；一個 Agent 也可以先後執行多次。執行環境離線時，Agent 的身分和歷史紀錄仍會保留，但新的執行必須等環境恢復連線。

## 參與工作的方式

- **負責任務**：將 Agent 設為負責人，執行排入佇列後便會開始處理。
- **處理一則留言**：在留言中 @提及 Agent，不變更任務負責人。
- **接續討論**：回覆 Agent 的留言，新資訊會納入後續執行。
- **直接聊天**：開始一段不依附於任務的聊天。
- **參與專案和小隊**：Agent 可以擔任專案 lead、小隊 leader 或小隊成員。
- **透過自動化執行**：依排程或外部事件觸發預先設定的工作，也可以手動執行。

Agent 可以建立任務、發表留言和變更工作狀態，但沒有收件匣，也不會收到 `@all`。@提及 Agent 會觸發執行，而不是發送通知。

## 權限與 Access

每個 Agent 都有一位 owner 和一項 Access 設定：

| Access | 誰可以執行 |
|---|---|
| **僅自己**（Only me） | 只有 Agent owner。 |
| **整個工作區**（Entire workspace） | 工作區中的所有成員。 |
| **指定成員**（Specific people） | Agent owner 和指定的成員。 |

新建 Agent 預設為 **Only me**。

<Callout type="info">
工作區 `owner` 和 `admin` 可以查看並管理所有 Agent，但無法繞過 Access 執行別人的 Only me Agent。一般成員只能看到自己擁有或有權執行的 Agent。
</Callout>

能否**查看** Agent 由擁有者身分、工作區管理角色和 Access 共同決定；Agent owner 和工作區 `owner`／`admin` 都能**修改**設定，但只有 Agent owner 能修改 Access。

環境變數和 MCP 等可能包含憑證的設定有更嚴格的讀取規則，請參閱[建立和設定 Agent](/agents-create#環境變數與憑證)。

## 在線、離線和工作狀態

Agent 清單會並列顯示兩種狀態：

- **可用性**由執行環境決定，例如在線、離線或不穩定。
- **工作狀態**由執行決定，例如執行中、排隊中或閒置。

"離線"不表示 Agent 已刪除。已排入佇列的執行會等到執行環境恢復；只有"已封存"代表 Agent 無法再接收新工作。

## 封存和還原

不再使用的 Agent 可以封存。封存後，Agent 不會出現在選擇器中，也無法指派或 @提及；歷史紀錄會保留，之後可以還原。

<Callout type="warning">
封存會取消該 Agent 所有尚未完成的執行，包括排隊中和執行中的項目。
</Callout>

Agent owner 和工作區 `owner`、`admin` 都可以封存或還原 Agent。
